3. INTRODUCTION

Random Forest is an established supervised machine learning algorithm widely used for both classification and regression tasks. Unlike traditional decision tree classifiers that rely upon a solitary hierarchical partitioning tree to formulate predictions, Random Forest builds an ensemble of multiple individual Decision Trees.

A conventional standalone Decision Tree is sensitive to small fluctuations in training data, exhibiting high variance and a strong predisposition toward overfitting. Random Forest overcomes this limitation through the foundational principle of Bagging (Bootstrap Aggregating). The algorithm generates multiple synthetic datasets via random sampling with replacement (bootstrapping) and trains an independent decision tree on each subset. Furthermore, during node splitting, Random Forest considers only a randomized subset of input features rather than the complete feature space. For classification, individual tree predictions are pooled, and the final class assignment is decided by majority voting.

6. THEORY OF RANDOM FOREST

Random Forest is an ensemble learning method that builds and combines multiple Decision Trees to produce a more accurate and stable prediction. Individual decision trees are known as weak or high-variance learners: they are prone to capturing noise and idiosyncrasies in the training partition. Random Forest mitigates variance by introducing two distinct levels of stochasticity:

  • Data Randomness (Bootstrap Sampling): Each tree in the forest is trained on an independently drawn bootstrap sample of the original dataset.
  • Feature Randomness (Random Subspace Method): When splitting a node during tree growth, only a randomly chosen subset of features \(m \le p\) is evaluated to determine the optimal split threshold, rather than considering all \(p\) features.

By forcing trees to use different subsets of data and features, the ensemble produces de-correlated trees. When their predictions are aggregated, individual errors cancel out, resulting in a model with substantially lower variance without sacrificing bias.

7. THEORY OF BAGGING (BOOTSTRAP AGGREGATING)

Bagging (short for Bootstrap Aggregating), proposed by Leo Breiman in 1996, is a parallel ensemble technique designed to enhance the stability and accuracy of machine learning algorithms.

1. Original Dataset \(\mathcal{D}\)
↓
2. \(B\) Bootstrap Samples \(\mathcal{D}_1^*, \dots, \mathcal{D}_B^*\)
↓
3. Train \(B\) Independent Models
↓
4. Aggregate Predictions (Majority Voting)
↓
5. Final Consensus

7.1 Bootstrapping (Sampling with Replacement)

Bootstrapping creates a new dataset of size \(N\) from an original dataset of size \(N\) by uniformly sampling observations with replacement. Because elements are replaced after being selected, individual observations may appear multiple times within a bootstrap sample, while others may not appear at all.

Mathematical Derivation: Out-of-Bag (OOB) Samples

For a dataset of \(N\) records, the probability of a record not being selected in a single draw is \((1 - 1/N)\). The probability it is omitted after \(N\) draws is:

\[P(\text{Omitted}) = \left(1 - \frac{1}{N}\right)^N \xrightarrow[N \to \infty]{} \frac{1}{e} \approx 0.368 \quad (36.8\%)\]

Consequently, each bootstrap sample contains roughly \(63.2\%\) of the original records. The remaining 36.8% of unselected observations (OOB samples) act as an inherent validation set, eliminating the need for a separate hold-out set.

7.2 Aggregating & Majority Voting

Aggregating combines the individual outputs of all \(B\) base models. In classification, each Decision Tree \(\mathcal{T}_b\) casts a unit vote for its predicted class \(\hat{y}_b(x)\). The ensemble's final prediction \(\hat{Y}(x)\) is determined by majority voting:

\[\hat{Y}(x) = \underset{c \in \mathcal{C}}{\operatorname{argmax}} \sum_{b=1}^{B} I\left(\hat{y}_b(x) = c\right)\]

Where \(I(\cdot)\) is the indicator function that equals 1 when tree \(b\) predicts class \(c\) and 0 otherwise. For instance, if 100 trees evaluate an Iris specimen and 88 predict Versicolor, 10 predict Virginica, and 2 predict Setosa, the final consensus classification is Versicolor.

7.3 Random Feature Selection (Subspacing)

If all features are evaluated at every split, multiple trees will inevitably select the single strongest predictor (e.g., Petal Length or Petal Width in Iris) for top-level splits, leading to highly correlated trees. Random Forest prevents this by selecting a random subset of \(m\) features at each split:

\[m = \lfloor\sqrt{p}\rfloor \quad \text{for classification} \quad (m = \lfloor\sqrt{4}\rfloor = 2 \text{ for Iris})\]

This ensures structural diversity across the trees, reducing inter-tree correlation \(\rho\) and maximizing the variance-reduction benefits of Bagging.

9. SINGLE DECISION TREE VS. RANDOM FOREST

A Single Decision Tree is a hierarchical rule-based classifier that creates axis-aligned splits based on feature thresholds that maximize Gini impurity reduction or Information Gain. While intuitive and computationally fast, single trees are notoriously fragile: small perturbations in the dataset cause radical shifts in tree topology, frequently causing the model to overfit complex training boundaries.

Comparative Analysis: Decision Tree Single vs. Random Forest Ensemble

Feature / Dimension Single Decision Tree Random Forest Ensemble
Architecture Single hierarchical tree with sequential binary splits. Ensemble forest composed of \(B\) independent de-correlated trees.
Overfitting Tendency High; readily memorizes training noise and outliers. Low; aggregation over multiple trees cancels out individual errors.
Model Variance High variance; highly sensitive to training data shifts. Substantially reduced variance due to bootstrap aggregation.
Feature Evaluation Evaluates all available input features at every split. Evaluates only a randomized subset (\(\sqrt{p}\)) of features per split.
Interpretability High; easily visualized as a flowchart of decision nodes. Moderate; aggregated ensemble requires feature importance analysis.
Prediction Output Single class assignment derived from one terminal leaf. Consensus class determined via majority voting across all trees.
Performance & Stability Vulnerable to test variance; unstable on unseen data. Consistently robust, stable, and highly generalizable.

9.1 Why Use Bagging? (Mathematical Justification)

The statistical power of Bagging stems from the variance of the average of \(B\) identically distributed random variables, each with variance \(\sigma^2\) and pairwise correlation \(\rho\):

\[\text{Var}(\text{Ensemble}) = \rho \sigma^2 + \frac{1 - \rho}{B}\sigma^2\]

As the number of trees \(B \to \infty\), the second term (\(\frac{1 - \rho}{B}\sigma^2\)) vanishes, leaving only \(\rho \sigma^2\). By introducing random feature selection, Random Forest actively minimizes the inter-tree correlation \(\rho\), driving the overall ensemble variance significantly below that of any individual tree.

10. CHARACTERISTICS OF RANDOM FOREST

  • Ensemble Architecture: Operates as a supervised bagging algorithm combining multiple base decision trees.
  • Dual Randomization: Combines bootstrap sample generation with random feature subspacing (\(m = \sqrt{p}\)).
  • Multi-Class Versatility: Handles binary and multi-class classification natively without requiring one-vs-rest transformations.
  • Resistance to Overfitting: Averaging over de-correlated trees limits variance, preventing over-specialization to training data.
  • Implicit Out-of-Bag Validation: Estimates out-of-sample generalization error during training via the \(\approx 36.8\%\) OOB data.
  • Built-In Feature Importance: Evaluates the relative discriminatory power of features based on mean decrease in Gini impurity.

15. CONCLUSION

In this assignment, the Bagging technique using the Random Forest algorithm was successfully designed, implemented, and thoroughly evaluated for multi-class classification on the Iris flower dataset. A comparative benchmark was established against a standalone single Decision Tree classifier.

The laboratory investigation yielded the following foundational insights:

  1. Bagging & Variance Reduction: Bootstrapping (random sampling with replacement) combined with aggregation effectively controls model variance. While a solitary Decision Tree is susceptible to overfitting noise within specific training splits, the ensemble aggregates 100 independently grown trees to provide stable and generalized predictions.
  2. De-Correlation via Feature Subspacing: By restricting candidate split evaluations to a random subset of \(m = \sqrt{p} = 2\) features, the Random Forest ensures structural diversity among trees, preventing dominant attributes (such as Petal Width and Petal Length) from producing identical split topologies.
  3. Out-of-Bag (OOB) Validation: The statistical derivation of OOB samples (\(\approx 36.8\%\) unused instances per tree) was experimentally confirmed, yielding an internal cross-validation score of 94.17%, validating model robustness without requiring an external validation split.
  4. Feature Significance: Gini impurity importance metrics quantitatively revealed that Petal Width (43.72%) and Petal Length (43.15%) together govern 86.87% of the classification decisions, with Sepal Width contributing minimally (1.50%).
  5. Majority Voting Consensus: The voting mechanics were directly demonstrated across test samples, illustrating how individual tree predictions are pooled to form an authoritative, robust consensus.

Overall, Random Forest represents a versatile, powerful, and practical ensemble classification framework that overcomes the fundamental variance and instability limitations of solitary decision trees.
