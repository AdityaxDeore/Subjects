5. Introduction & Theory

The Knapsack Problem is a highly studied combinatorial optimization problem. Imagine you have a knapsack or a spacecraft with a fixed carrying capacity, and you must choose from a set of items, each with a specific weight and value. The goal is to pack the knapsack such that the total value is as large as possible.

Types of Knapsack Problems

Algorithm Type Core Description Optimal Strategy Used
Fractional Knapsack Items are highly divisible like liquids or powders. You can take a fraction of an item. Greedy Algorithm
0/1 Knapsack Items are indivisible like computers. You must take the whole item or leave it. Dynamic Programming
Bounded Knapsack Items can be selected, but only up to a strictly limited maximum quantity. Dynamic Programming

Fractional vs. 0/1 Knapsack: A Closer Look

The key differentiator is divisibility. In the Fractional variant, because we can divide items, we can simply sort all items by their value-to-weight ratio and greedily consume them from highest ratio to lowest. This guarantees an optimal mathematical solution. In the 0/1 variant, greedily taking the highest ratio item might leave awkward empty gaps in the knapsack that cannot be filled, making the greedy approach fail.

Mathematical Representation

The problem can be modeled mathematically as a linear programming constraint:

Objective Function (Maximize Value):

\[ \text{Maximize } Z = \sum_{i=1}^{n} (v_i \cdot x_i) \]

Subject to Capacity Constraints:

\[ \sum_{i=1}^{n} (w_i \cdot x_i) \leq W \]

Variables (Fractions allowed):

\[ 0 \leq x_i \leq 1 \quad (\text{for all } i = 1, 2, \dots, n) \]

Real-World Applications

  • Satellite payload planning and spacecraft launch loadouts in Aerospace.
  • Allocating fractional CPU and Memory resources to server nodes in Cloud Computing.
  • Stock portfolio optimization and fractional investment distributions in Finance.
  • Loading delivery trucks with bulk goods like grains or liquids in Logistics.

6. Example: Fractional Knapsack Optimization

To fully grasp the algorithm, consider a knapsack with a maximum capacity of 15 kg.

Item Value ($) Weight (kg) Ratio (V/W) Priority Rank
C$502 kg25.01st (Highest)
B$1507 kg21.42nd
A$1005 kg20.03rd (Tie)
D$20010 kg20.03rd (Tie)
E$303 kg10.05th (Lowest)

Step-by-Step Greedy Execution

  1. Initial State: Remaining Capacity = 15 kg, Total Value = 0.
  2. Load Item C: Weight is 2 kg. 2 < 15, so add fully. Remaining = 13 kg, Value = 50.
  3. Load Item B: Weight is 7 kg. 7 < 13, so add fully. Remaining = 6 kg, Value = 50 + 150 = 200.
  4. Load Item A: Weight is 5 kg. 5 < 6, so add fully. Remaining = 1 kg, Value = 200 + 100 = 300.
  5. Load Item D (Fractional): Item D weighs 10 kg, but only 1 kg remains. We take exactly 1/10th of item D. Value increase = (1/10) * 200 = 20. Remaining = 0 kg, Total Value = 320.
  6. Conclusion: The knapsack is fully packed at 15 kg, yielding an optimal max value of 320.

7. Java Implementation

class Item {  
    String name;    
    int value;    
    int weight;    
    boolean divisible;  
    
    Item(String name, int value, int weight, boolean divisible) {        
        this.name = name;        
        this.value = value;        
        this.weight = weight;        
        this.divisible = divisible;    
    }
}  

public class MarsFractionalKnapsack {  
    public static void fractionalKnapsack(Item arr[], int capacity) {  
        int n = arr.length;  
        // Sort items by Value/Weight Ratio in descending order
        for (int i = 0; i < n - 1; i++) {  
            for (int j = i + 1; j < n; j++) {  
                double ratio1 = (double) arr[i].value / arr[i].weight;                
                double ratio2 = (double) arr[j].value / arr[j].weight;  
                if (ratio2 > ratio1) {  
                    Item temp = arr[i];                    
                    arr[i] = arr[j];                    
                    arr[j] = temp;                
                }            
            }        
        }
        int currentWeight = 0;        
        double totalValue = 0;  
        System.out.println("\n===== MARS SPACE MISSION CARGO OPTIMIZATION =====");        
        System.out.println("Maximum Payload : " + capacity + " kg\n");  
        System.out.printf("%-30s %-15s %-10s\n", "Cargo Item", "Loaded", "Priority");        
        System.out.println("--------------------------------------------------------------");        
        for (int i = 0; i < n; i++) {  
            if (currentWeight + arr[i].weight <= capacity) {  
                currentWeight = currentWeight + arr[i].weight;                
                totalValue = totalValue + arr[i].value;  
                System.out.printf("%-30s %-15s %.2f\n", arr[i].name, "100%", (double) arr[i].value / arr[i].weight);  
            } else {  
                int remaining = capacity - currentWeight;  
                if (remaining > 0 && arr[i].divisible) {  
                    double fraction = (double) remaining / arr[i].weight;  
                    totalValue = totalValue + arr[i].value * fraction;  
                    currentWeight = capacity;  
                    System.out.printf("%-30s %-15s %.2f\n", arr[i].name, String.format("%.2f%%", fraction * 100), (double) arr[i].value / arr[i].weight);                
                }  
                break;          
            }        
        }  
        System.out.println("--------------------------------------------------------------");        
        System.out.println("Payload Used        : " + currentWeight + " kg");        
        System.out.println("Remaining Capacity  : " + (capacity - currentWeight) + " kg");        
        System.out.printf("Total Mission Value : %.2f\n", totalValue);    
    }  
    
    public static void main(String args[]) {  
        int capacity = 120;  
        Item arr[] = {  
                new Item("Oxygen Tanks", 500, 20, true),                
                new Item("Medical Oxygen", 360, 15, true),                
                new Item("Drinking Water", 400, 20, true),                
                new Item("Rocket Fuel", 800, 50, true),                
                new Item("Food Rations", 300, 20, true),                
                new Item("Laboratory Chemicals", 280, 18, true), 
                new Item("Medical Kit", 260, 25, false),                
                new Item("Scientific Instrument", 350, 35, false)
        };  
        fractionalKnapsack(arr, capacity);    
    }
}

9. Implementation Details

The logic operates on a strict greedy principle. Each cargo item is initialized with a mission value and a physical weight. The algorithm computes the value-to-weight ratio for every item, functioning as an efficiency metric. Using a Bubble Sort algorithm, items are ordered descending by this metric. The loop then continuously adds the most efficient items to the payload. If an item breaches the maximum capacity, and the divisible flag is true, a fractional percentage is calculated and added to perfectly cap the spacecraft at 100 percent payload capacity.

10. Time & Space Complexity Analysis

  • Time Complexity is O(n²). While the ratio calculation and cargo selection are linear, the implementation utilizes Bubble Sort to sort the items, which dominates the time complexity.
  • Space Complexity is O(1) auxiliary space. Sorting is done in-place without the need for additional data structures, making it extremely memory efficient.

11. Comparison of Sorting Algorithms

Sorting Algorithm Time Complexity Suitability for Knapsack
Bubble Sort (Implemented) O(n²) Good for small lists, easy to code, but scales poorly.
Merge Sort O(n log n) Highly recommended for large production datasets.
Quick Sort O(n log n) Very fast in practice, standard in most library functions.

12. Algorithmic Advantages

  • Guaranteed Optimality. Unlike some greedy applications, the greedy strategy for the Fractional Knapsack guarantees the mathematically optimal maximum value.
  • High Efficiency. The algorithm is incredibly fast and operates with virtually zero memory overhead.
  • Real-world Flexibility. Perfectly models logistics scenarios where goods like liquids and raw materials can be split dynamically.

13. Limitations & Constraints

  • Strict Divisibility Rule. The entire logic fails if items cannot be divided for example you cannot load half of a laptop. For scenarios like this, Dynamic Programming is strictly required.
  • Bubble Sort Bottleneck. The current implementation uses an O(n²) sort, which will slow down significantly if computing thousands of cargo items simultaneously.
