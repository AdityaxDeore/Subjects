Tasks to be Performed

Part A: Load and Understand the Data

  1. Load the dataset using pandas.read_csv()
  2. View the first few rows using .head()
  3. Display column names, data types, and dataset shape
  4. Identify missing data using .isnull().sum()

Part B: Handle Missing Data

  1. Replace missing numerical values with the mean of the column (if any)
  2. Replace missing categorical values with the mode
  3. Drop columns with excessive missing values (if justified)

Part C: Normalize Numerical Features

  1. Select important numerical columns such as: CreditScore, Age, Balance, EstimatedSalary
  2. Apply Min-Max Normalization or Z-score Standardization using NumPy:

Part D: Encode Categorical Variables

  1. Apply Label Encoding or One-Hot Encoding to: Gender, Geography
  2. Use pd.get_dummies() for one-hot encoding with drop_first=True to avoid multicollinearity

Part E: Final Check

  1. Combine all cleaned columns into a new DataFrame
  2. Ensure no missing values remain
  3. Confirm that all categorical columns are now numeric
  4. Save the final preprocessed data as a new CSV

# PART B: HANDLE MISSING DATA
# ============================================================

# Identify numerical columns
numerical_columns = df.select_dtypes(
    include=np.number
).columns

# Identify categorical columns
categorical_columns = df.select_dtypes(
    include="object"
).columns

print("Numerical Columns:")
print(numerical_columns.tolist())

print("\nCategorical Columns:")
print(categorical_columns.tolist())

# Fill missing numerical values with the mean
for column in numerical_columns:
    if df[column].isnull().sum() > 0:
        df[column] = df[column].fillna(
            df[column].mean()
        )

print("Numerical missing values filled with mean.")

# Fill missing categorical values with the mode
for column in categorical_columns:
    if df[column].isnull().sum() > 0:
        df[column] = df[column].fillna(
            df[column].mode()[0]
        )

print("Categorical missing values filled with mode.")

# Check missing values after treatment
print("Missing Values After Preprocessing:")

remaining_missing = df.isnull().sum()

display(
    remaining_missing.to_frame("Missing Values")
)

print(
    "Total Missing Values:",
    remaining_missing.sum()
)

# PART C: NORMALIZE NUMERICAL FEATURES
# ============================================================

# Select important numerical features
selected_features = [
    "age",
    "salary",
    "experience",
    "performance_score"
]

print("Features Selected for Normalization:")
print(selected_features)

# Min-Max Normalization
#
# Formula:
# X_scaled = (X - X_min) / (X_max - X_min)

for column in selected_features:

    minimum = np.min(df[column])
    maximum = np.max(df[column])

    df[column + "_normalized"] = (
        (df[column] - minimum) /
        (maximum - minimum)
    )

print("Min-Max Normalization completed.")

# Display original and normalized values together
comparison = df[
    [
        "age",
        "age_normalized",
        "salary",
        "salary_normalized",
        "experience",
        "experience_normalized",
        "performance_score",
        "performance_score_normalized"
    ]
].head()

print("Original vs Normalized Values:")
display(comparison)
