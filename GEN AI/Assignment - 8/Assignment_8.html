Theory: Recurrent Networks & LSTM Cells

1. The Need for LSTMs over Simple RNNs

Standard Recurrent Neural Networks (RNNs) suffer from the vanishing gradient problem. When learning long sentences, the gradient signal decays exponentially as it propagates back through time steps, causing early words to be completely forgotten. Long Short-Term Memory (LSTM) networks solve this using a dedicated cell state ($C_t$) and three gating mechanisms that regulate what to retain, what to add, and what to emit.

2. Intuitive Gate Functions (Summary)

  • Forget Gate ($f_t$): Reads previous hidden state $h_{t-1}$ and current input $x_t$, outputting numbers between 0 (completely forget) and 1 (completely retain).
  • Input Gate ($i_t$ & $\tilde{C}_t$): Identifies which new features from the incoming word are worth committing into memory, combined with a $\tanh$ candidate state.
  • Cell State Update ($C_t$): Multiplies old memory by the forget gate and adds scaled new candidate information ($C_t = f_t \cdot C_{t-1} + i_t \cdot \tilde{C}_t$).
  • Output Gate ($o_t$ & $h_t$): Filters the cell memory through $\tanh$ and decides what to emit as the step's hidden prediction state $h_t$.

Step-by-Step Algorithm

  1. Load Dataset: Import standard libraries (TensorFlow, Pandas, NumPy) and load the 25-sentence Generative AI domain corpus.
  2. Text Cleaning: Convert text to lowercase, strip leading/trailing spaces, and remove punctuation using regular expressions.
  3. Vocabulary Tokenization: Fit Keras Tokenizer to create an index of 121 unique words (total vocabulary size is 122 including index 0 reserved for padding).
  4. Generate N-grams: Deconstruct each sentence into expanding sequences of tokens (e.g. $[w_1, w_2]$, $[w_1, w_2, w_3]$).
  5. Apply Pre-Padding: Pad all n-gram sequences to the maximum length (13 tokens) using padding='pre'.
  6. Split Predictors & Target: Split sequences into $X$ (first 12 tokens) and $y$ (last token as label).
  7. Build Architecture: Add an Embedding layer (64-dim), an LSTM layer (128 units), and a Dense softmax layer (122 classes).
  8. Compile & Train: Compile with Adam optimizer and sparse_categorical_crossentropy; train for 200 epochs.
  9. Generate Text: Provide seed words, scale predicted word logits using a temperature factor, and sample successive words.

Part F: Generate Text with Temperature Control

index_to_word = {index: word for word, index in tokenizer.word_index.items()}

def generate_text(seed_text, next_words, temperature=0.7):
    for _ in range(next_words):
        # Convert the current text to a padded sequence
        tokens = tokenizer.texts_to_sequences([seed_text.lower()])[0]
        tokens = pad_sequences([tokens], maxlen=max_len - 1, padding='pre')
        
        # Predict probabilities of the next word
        probs = model.predict(tokens, verbose=0)[0].astype('float64')
        
        # Apply temperature and pick the next word
        probs = np.log(probs + 1e-8) / temperature
        probs = np.exp(probs) / np.sum(np.exp(probs))
        next_index = np.random.choice(len(probs), p=probs)
        
        seed_text += " " + index_to_word.get(next_index, "")
    return seed_text

Temperature ($T$) Sampling Behavior Output Characteristics
Low ($T = 0.5$) Sharpens distribution towards maximum probability. Highly predictable, safe, strictly follows training text.
Medium ($T = 0.7$) Balanced exploration and exploitation. Fluent grammar with natural sentence flow.
High ($T = 1.0$) Flattens distribution, giving lower-ranked tokens a chance. Creative, varied word selections, higher lexical diversity.

Theory & Viva Questions with Model Answers

Q1. Why are LSTMs preferred over traditional RNNs for text generation?

Ans: Traditional RNNs suffer from vanishing gradients when backpropagating through long sequences, which erases context from earlier words. LSTMs introduce an internal cell state ($C_t$) and three gates (forget, input, output) that act as an error carousel, preserving long-range syntactic and grammatical dependencies.

Q2. Why is left-padding (pre-padding) necessary instead of post-padding?

Ans: In LSTMs, the hidden state at the final time step is used to predict the next word. With pre-padding (`padding='pre'`), the padding zeros occur at the beginning, meaning the model processes actual word tokens at the latest steps right before the prediction. Post-padding would overwrite the active memory with uninformative zero tokens.

Q3. What is the role of Temperature in text generation?

Ans: Temperature scales the logits before the softmax activation ($\text{logit} / T$). A low temperature ($T < 1$) concentrates probability on the top word, producing deterministic output. A higher temperature ($T \ge 1$) flattens the distribution, giving alternative words a non-zero chance of selection to promote novelty.

Q4. Why use sparse_categorical_crossentropy instead of categorical_crossentropy?

Ans: sparse_categorical_crossentropy accepts integer target labels directly ($y \in [0, V-1]$) without requiring one-hot encoded vectors. This significantly saves memory and computational overhead, especially as the vocabulary size grows.

Q5. Why is an Embedding layer used instead of one-hot encoded vectors as input?

Ans: One-hot vectors are high-dimensional, sparse, and treat all words as orthogonal (distance between all words is identical). An Embedding layer transforms each word into a low-dimensional dense vector ($\mathbb{R}^{64}$) where words with similar contextual meanings cluster closer together.
