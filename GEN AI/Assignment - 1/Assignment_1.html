1. Python for Data Science

Python is one of the most popular programming languages for data science and machine learning. It provides a simple syntax, vast libraries, and strong community support. Libraries like Pandas, NumPy, and Matplotlib allow users to load, clean, manipulate, and visualize data efficiently.

  • Pandas is used for reading CSV files and manipulating tabular data using DataFrames.
  • NumPy supports high-performance numerical operations with arrays and matrices.
  • Matplotlib/Seaborn can be used for data visualization (optional in this practical).

2. Understanding the Dataset

The dataset used in this assignment (Churn_Modelling.csv) represents customer information from a bank. It includes both categorical (e.g., Gender, Geography) and numerical (e.g., Age, Balance) features. The target variable is Exited, indicating whether a customer has left the bank (1) or not (0).

Before feeding data into a machine learning or deep learning model, preprocessing is essential. This includes:

  • Handling missing values.
  • Encoding categorical variables.
  • Normalizing numerical features.

These steps ensure better model accuracy and stability during training.

3. Introduction to TensorFlow 2 and Tensors

TensorFlow 2 is an open-source deep learning framework developed by Google. It simplifies the process of building and training machine learning models. At its core, TensorFlow uses a data structure called a tensor.

A tensor is a generalization of scalars (0D), vectors (1D), and matrices (2D) to n-dimensional arrays. TensorFlow operations work with these tensors to build complex models.

Common Tensor Operations:

  • tf.convert_to_tensor(): Converts data to a tensor.
  • tf.shape(): Returns the shape of the tensor.
  • tf.rank(): Returns the number of dimensions (rank).
  • tf.math.reduce_mean() and tf.math.reduce_sum(): Aggregate operations useful for statistics.
  • tf.linalg.matmul(): Matrix multiplication.

Understanding how to manipulate tensors is a critical first step in implementing any deep learning model.
